## ✨ Features
1. **Welcome Screen** — Pastel theme, animated bow, interactive quick start.
2. **Live Countdown** — Animated cake, candles, live birthday countdown timer.
3. **Memories Scrapbook** — 3 tabs: Polaroid scrapbook, memorable moments, and sticky notes.
4. **Mystery Gift Boxes** — 6 interactive surprise boxes with confetti animations.
5. **Music Player** — Audio playback controls, progress bar, playlist, and Spotify link.
6. **Handwritten Letter** — Authentic stationery paper with personal birthday message.
7. **The Grand Celebration** — Cosmic starry celebration with balloons, fireworks, and final surprise.
8. **Slide-out Drawer Menu** — Fast navigation, profile customizer, and settings editor.

## 🚀 Enabling GitHub Pages
1. Open the repository on GitHub: [https://github.com/jackhany96-gif/sherly-birthday1024](https://github.com/jackhany96-gif/sherly-birthday1024)
2. Click **Settings** (tab at the top).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** > **Source**:
   - Choose **Deploy from a branch**
   - Branch: Select **`main`** or **`gh-pages`**, folder: **`/ (root)`**
   - Click **Save**
   *(Note: Make sure your repository visibility is set to **Public** under Settings > General > Danger Zone if using a free GitHub account).*
5. Within 1–2 minutes, your live website will be live at:
   **`https://jackhany96-gif.github.io/sherly-birthday1024/`**

## 📱 Add to Phone Home Screen (Looks like a Native App)
- **iPhone (Safari)**: Tap the Share button (square with arrow pointing up) -> scroll down -> tap **Add to Home Screen**.
- **Android (Chrome)**: Tap the 3 dots menu -> tap **Add to Home screen** / **Install App**.
